# JRCv1 adoption checklist: charter

From an automated scan of https://github.com/jollyrogercharter/charter @ 37365e1. Tick items as you finish them; re-run the scan to check.

- [ ] **Add jrc.json from the candidate below, fill in the assessor, and review every claim** (high impact, small effort). Starter file: <code>jrc.json</code>
- [ ] **Say whether the project holds user data and, if so, how people control it** (high impact, small effort). Starter file: <code>DATA.md</code>
- [ ] **Add CONTRIBUTING.md: how to propose a change and how it gets decided** (high impact, small effort). Starter file: <code>CONTRIBUTING.md</code>
- [ ] **Give a second, independent person the rights to review, merge and release** (high impact, medium effort)
- [ ] **Document (and test) how a user exports their data and moves it elsewhere** (high impact, large effort)
- [ ] **Add SECURITY.md: how to report a vulnerability and who responds** (medium impact, small effort). Starter file: <code>SECURITY.md</code>
- [ ] **Commit the deployment configuration (container, IaC or host config)** (medium impact, medium effort)
- [ ] **Say how the project is funded, even if the answer is 'it isn't'** (low impact, small effort)
- [ ] **Run jrc check and publish the report in the repository** (medium impact, small effort)
- [ ] **Ask someone unaffiliated to take the Jolly Roger Challenge** (high impact, medium effort)
