## Decisions

- **One capability layer, five front ends.** Every capability is a pure function in `lib/`. WebMCP (`site/assets/webmcp.js`), the stdio MCP server (`bin/jrc-mcp.mjs`), `jrc tool NAME`, the static `/api/v1/` files and the page forms all call it through the same `runTool`, so they can't disagree. A test compares them.
- **Read-only or prepare-only, by construction.** Nothing in `lib/` or `bin/` posts, publishes, signs in or changes infrastructure. Drafts, PR bodies, challenge packages and AT Protocol requests are returned for a person to submit from their own account. Publishing records with the user's own AT Protocol account is listed as *planned*, not built.
- **A versioned capability manifest** (`/api/v1/capabilities.json`, schema `spec/capabilities-0.1.schema.json`) states each capability's safety class, network use, maturity and real interfaces, and how each interface was actually verified. The AT Protocol tools are `draft` because their Lexicons are proposals.
- **MCP 2026-07-28 plus legacy `initialize`.** The modern protocol is stateless with per-request `_meta`; most clients in use still send `initialize`, so both are served. 2025-03-26 isn't offered because it requires batches.
- **Money in whole cents; recurring totals in yearly cents.** Unknown is never zero, including an unstated migration cost, which is now a required field.
- **Links are fork-configurable.** `REPO_URL` and `SITE_URL` reach every generated link through `lib/jrc/site-config.mjs`.

## Audits (Claude Sonnet, commit 54d193f) and fixes

These reviewers are agents working for the project, not independent auditors. Each finding below was reproduced by the reviewer; each fix has a regression test, and the security and claims fixes were confirmed to fail on the old code where that was practical.

**Spec compliance and vendor dependence** (fixed in c298ae2): `server/discover` and `tools/list` lacked `ttlMs`/`cacheScope`; `-32022` listed legacy versions a modern client couldn't use; 2025-03-26 was advertised without batch support; cancelled requests got an error response instead of none; duplicate in-flight ids could clobber each other; the manifest named CLI commands that don't exist or don't run the same path (now `cli` is always `jrc tool NAME`, with `cli_shortcut` for related commands); our datetime check accepted values the reference library rejects.

**Security and privacy** (fixed in 7cccba7): `prepare_cost_reduction_pr` skipped the privacy scan for title, risks, tests, measurement and the migration assumption; the shared scanner missed Anthropic, OpenAI project, Google keys, webhook URLs, non-http credentials in URLs, Basic auth and `*_TOKEN=` assignments; `export_atproto_record` could label a hand-edited snapshot an `automated-scan` (now `replayed-snapshot`, bound by `snapshotSha256`); exports skipped the privacy scan and record links accepted `javascript:`; long non-ASCII drafts overflowed output caps and GitHub's URL length; cost totals could exceed exact integer range; assumptions were dropped silently past 20; validation errors echoed caller-chosen keys; debate text from the repository was returned as trusted and copied raw into drafts; the MCP reader buffered whole lines before checking size; CLI JSON errors echoed file contents; the site had no Content-Security-Policy (now `site/_headers`).

**Accessibility, fallback and reproducibility** (fixed in aa4013a and the final commit): links were hardcoded to this repository, so forks filed issues here; the sub-path hosting advice was wrong (root or custom domain only); the provenance tests failed in shallow clones (now skipped, and the docs say so); errors were announced as unrelated messages and stale live-region text stayed; the hash checker hung without Web Crypto and dropped files past 50 silently; results weren't focus-managed; the new forms had no styling; scrollable tables and code blocks weren't keyboard-reachable or labelled. Not fixed: no screen-reader or keyboard-only test by a person has been done.

**Claims, transparency and provenance** (fixed in the final commit): this run record and the CHANGELOG entry were missing; `status.json` verification times were set about 75 minutes in the future and are now real times; every capability was labelled `implemented` (AT Protocol tools are now `draft`, and the manifest says how each interface was verified); the cost tools treated a missing migration cost as zero; `get_debate` presented launch-time text as current and claimed an objection where none was stated; the WebMCP status implied the 29 tools ran in Chrome when the real-browser check covered the original 13; `prepare_challenge_submission` returned `independent` (now `independence_claimed`); provenance summaries were labelled `verified` and gave no hint that 8 founding files were legitimately edited after preservation (now `changed_since_preservation`, and a mismatch on such a file says so); a claim that digests are "recomputed on every build" was false; the timestamp verifier is named as the project's AI agent; the docs understated output caps and network use.
