# The site is live

https://jollyrogercharter.org now serves this site from the public [charter repository]({{ repoUrl }}). Cloudflare Pages rebuilds it from `main` on every merge, on the free plan, with no analytics and no cookies.

You don't have to trust that the live site matches the repository: anyone can rebuild the whole site with `npm ci && npm test`.

Still open: a licence decision and a second maintainer. [OPEN-DEPENDENCIES.md]({{ repoUrl }}/blob/main/OPEN-DEPENDENCIES.md) tracks each one.
